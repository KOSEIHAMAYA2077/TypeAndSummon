# Type & Summon 提出用 README

## 概要

Type & Summon は、Java Swing と TCP/HTTP 通信で動作するリアルタイムタイピングゲームです。

| 項目 | 内容 |
|------|------|
| 対戦モード | **1対1対戦**（3分） / **2人協力ボス戦**（10分・ボス Lv1〜5 連戦） |
| ロビー | HTTP（部屋作成・参加） |
| 対戦中 | TCP ソケット（入力・HP・ログのリアルタイム同期） |
| 正本 | ゲーム状態・正誤判定はすべて **サーバー側** |
| 必要 Java | **Java 17 以上**（確認環境: javac 24） |

```text
client/  … クライアント（GUI・素材・実行スクリプト）
server/  … サーバー（対戦ロジック・DB・実行スクリプト）
```

## 必要環境

- **JDK 17+**（`java` / `javac` が PATH に通っていること）
- **Windows**: PowerShell 5.1 以上、または Git Bash
- **サーバー**: `server/lib/sqlite-jdbc.jar`（単語 DB 読み込み用）
- **クライアント**: `client/lib/jlayer-1.0.1.jar`（MP3 BGM 再生用。`run.ps1` が無い場合は自動取得）

## 起動方法

**必ずサーバーを先に起動**し、その後クライアントを起動してください。  
コードを変更した場合は、**サーバー・クライアント両方**を再起動すると反映されます。

### Windows（PowerShell）— 推奨

#### 1. サーバー

```powershell
cd server
.\run.ps1
```

- 起動前に **8080（HTTP）・9090（TCP）** を使用中のプロセスを自動停止します
- 単語 DB の準備 → コンパイル → サーバー起動まで一括で行います
- 成功時の表示例:
  - `HTTP server listening on 127.0.0.1:8080`
  - `TCP socket server listening on 127.0.0.1:9090`

既存プロセスを止めずに起動したい場合:

```powershell
.\run.ps1 -NoKillExisting
```

#### 2. クライアント

**別の PowerShell ウィンドウ**を開き:

```powershell
cd client
.\run.ps1
```

- コンパイル後、`ui.SushiBattleGUI` が起動します
- 2人で遊ぶ場合は、**さらに別ウィンドウ**でもう 1 回 `.\run.ps1` を実行します

### Git Bash / Linux / macOS

#### 1. サーバー

```bash
cd server
./run.sh
```

#### 2. クライアント

```bash
cd client
./run.sh
```

2人対戦・2人協力とも、クライアントを **2 インスタンス** 起動します。

### 手動コンパイルのみ

```bash
# サーバー
cd server && ./build.sh

# クライアント
cd client && ./build.sh
```

## プレイの流れ

### 1対1 対戦モード

1. タイトル画面 → **対戦開始**
2. 名前・ルーム名を入力（作成 / 参加）
3. 2 人が揃うと **3 分** の対戦開始
4. Lv1〜9 の単語をタイピングし、相手 HP を 0 にするか、時間切れ時 HP 多い方が勝利

### 2人協力モード（ボス戦）

1. タイトル画面 → **協力モード**
2. 名前・Room Name を入力（作成 / 参加）
3. **同じ Room Name** で 2 人目が参加すると自動でボス戦開始（**制限時間 10 分**）
4. ボス Lv1 → Lv5 を順に撃破すると **協力クリア**
5. 全員 HP 0 または時間切れで敗北

協力モードの詳細は [協力モード（ボス戦）](#協力モードボス戦) を参照してください。

## 協力モード（ボス戦）

### 基本ルール

| 項目 | 値 |
|------|-----|
| プレイ人数 | 2 人（TCP 接続 2 + ゲスト参加完了で開始） |
| 制限時間 | **10 分**（600 秒） |
| プレイヤー HP | 各 1500（タイピング正解で回復） |
| ボス HP | ボスごとに異なる（`CooperativeBossProfile`） |
| ボス攻撃 | **5 秒ごと**（Lv4 のみ全員同時攻撃） |
| タイピング | 各プレイヤーが **独立した単語** を入力（相手と単語は共有しない） |
| 勝利条件 | ボス Lv5 撃破 |
| 敗北条件 | **全員 HP 0** または時間切れ |

### ボス一覧

| ボス | HP | 攻撃 | 攻撃対象 | 特殊能力 |
|------|-----|------|----------|----------|
| Lv1 | 500 | 50〜70 | ランダム 1 人 | なし |
| Lv2 | 800 | 80〜120 | ランダム 1 人 | なし |
| Lv3 | 1,200 | 120〜150 | ランダム 1 人 | **Lv9 強制**（下記） |
| Lv4 | 1,500 | **100（全体）** | **全員** | **3 文字目ごとに隠す**（下記） |
| Lv5 | 2,000 | 150〜180 | ランダム 1 人 | **罠単語**（下記） |

ボス撃破後は **3 秒** の交代演出（入力不可）のあと、次のボス戦が始まります。

### ボス特殊能力の詳細

#### Lv3 — Lv9 単語強制

- **15 秒周期**（**10 秒 ON** / **5 秒 OFF**）で発動
- 発動中は Lv1〜8 のレベルボタンがロックされ、`assets/bossbattle/chain.png` が表示される
- 単語は **Lv9 のみ**
- **入力中の単語がある場合**: その単語を **正解またはミスで完了してから** Lv9 に移行（途中で単語が切り替わらない）
- スキル終了後は通常の選択レベルに戻る

#### Lv4 — 単語の一部を隠す

- 表示上、単語の **3 の倍数文字目**（3, 6, 9…）を **1 秒隠す / 1 秒表示** で点滅
- 判定・入力自体は通常どおり（見えない文字もタイピング可能）
- 攻撃は **全プレイヤーに 100 ダメージ** の全体攻撃

#### Lv5 — 罠単語

- 配布される単語の **3 単語に 1 回**、ランダム文字列の罠単語
- 罠単語を正解しても **ボスにダメージは入らない**（回復のみ）

### HP 0 になったプレイヤー

- **入力欄・レベルボタン・数字キーが無効** になる
- パートナーが生存していれば **戦闘は継続**（観戦状態）
- **全員 HP 0** で `party_wiped` として協力戦終了

## 追加実装・変更事項（提出版）

本提出物に含まれる主な追加・改善内容です。


### 協力モード全体

- 2 人協力ボス戦（Lv1〜5 連戦）のサーバー・クライアント実装
- 共有ボス HP・各プレイヤー独立タイピング・共有バトルログ
- ボス画像（`assets/bossbattle/lv1.png` 〜 `lv5.png`）とボス攻撃アニメーション

### 協力モード — ゲームプレイ

- Lv3 スキル: 入力中単語完了後に Lv9 へ移行（`pendingLv9Transition`）
- Lv3 スキル周期: 15 秒（10 秒 ON / 5 秒 OFF）
- Lv4 攻撃力: 100（全体攻撃）
- HP 0 プレイヤーの入力ロック（サーバー拒否 + クライアント UI 無効化）
- Lv1〜2 でも反動 0 のミスを正しく通知（`TypingResult.miss` フラグ）

### UI・演出

- ボス戦時: 英単語・結果表示に文字幅に合わせた半透明白背景
- Lv4: 単語カバーオーバーレイ（1 秒隠す / 1 秒表示）
- ダメージ数字のフローティング表示、背景キャッシュ、ボスアニメの translate 化（パフォーマンス改善）
- 決着後「メニューへ戻る」ボタン

### 音声（`GameAudio`）

- BGM: MP3 ループ（`lib/jlayer-1.0.1.jar`）
- 効果音: WAV / MP3 自動フォールバック（`.wav` が無ければ `.mp3` を試行）
- 協力ボス攻撃 SE: ボス Lv 別（`sfx/lv1.mp3`, `lv3`, `lv4`, `lv5` など）
- 詳細: `client/assets/audio/README.md`

## 設定ファイル（.env）

### サーバー `server/.env`

必要な場合は `server/.env` を作成して使用します。未作成時は既定値で動作します。

```env
SERVER_HOST=127.0.0.1
SERVER_PORT=8080
SOCKET_HOST=127.0.0.1
SOCKET_PORT=9090
PUBLIC_SOCKET_HOST=127.0.0.1
SQLITE_URL=jdbc:sqlite:data/game_server.db
```

| 変数 | 説明 |
|------|------|
| `SERVER_PORT` | HTTP ロビー API |
| `SOCKET_PORT` | TCP 対戦通信 |
| `PUBLIC_SOCKET_HOST` | クライアントへ返す TCP 接続先（LAN 越しの場合はサーバー PC の IP） |

### クライアント `client/.env`

必要な場合は `client/.env` を作成して使用します。未作成時は `http://localhost:8080` を使用します。

```env
API_BASE_URL=http://localhost:8080
```

別マシンから接続する場合は `http://<サーバーIP>:8080` に変更してください。

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| ポート使用中エラー | `server\run.ps1` を実行（自動で 8080/9090 を解放） |
| クライアントが接続できない | サーバーが先に起動しているか確認。`.env` の URL / ポートを確認 |
| 変更が反映されない | サーバー・クライアント **両方** を再起動 |
| BGM（MP3）が鳴らない | `client/lib/jlayer-1.0.1.jar` があるか確認。`run.ps1` 実行で自動取得可 |
| 協力モードが始まらない | 同じ Room Name で **2 人** が TCP 接続完了しているか確認 |
| 古いサーバーが残っている | PowerShell: `cd server; .\run.ps1`（推奨）または Git Bash で Ctrl+C 後に `./run.sh` |
